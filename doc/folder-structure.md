## Required subfolders

### `Data/`
- **Submit:** folder + **only** the final CSV.
- **Do not submit:** tubCloud originals (`Fahrzeug/`, `Zulassungen/`, …).
- Examiners place original data here and re-run notebooks.

### `Additional_files/`
- App screenshots (`01`–`05_*.png`).
- `Dashboard_User_Guide.md` — dashboard user guide for examiners.
- Other extras that do not belong elsewhere.

### `www/`
- App static assets: `style.css`, `fonts/`, `img/` (logos).
